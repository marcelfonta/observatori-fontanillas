Stellarium: privacitat, llicència i atribució

El planetari pilot mostra l’aplicació oficial Stellarium Web dins un marc aïllat. El visor només s’activa quan la persona prem «Explora el cel»; fins aleshores el navegador no connecta amb Stellarium ni descarrega els seus catàlegs.

Servei extern i privacitat

En activar-lo, el navegador connecta directament amb stellarium-web.org i els serveis necessaris de Stellarium. Aquests serveis poden rebre dades tècniques habituals, com l’adreça IP i la informació del navegador, i mostren el seu propi avís de galetes. L’Observatori no envia cap nom, correu ni identificador de compte.

  • Obrir Stellarium Web directament
  • Política de privacitat de Stellarium Labs

Llicència i codi font

Stellarium Web i Stellarium Web Engine són projectes de Stellarium. L’Observatori no en redistribueix ni modifica el motor, el WebAssembly, els estils o els catàlegs: només enllaça el servei oficial amb la localitat, l’hora i l’orientació escollides.

  • Codi font de Stellarium Web
  • Codi font de Stellarium Web Engine
  • Llicència AGPL-3.0 del motor

Continuïtat accessible

Si el servei extern, WebGL o WebAssembly no estan disponibles, les targetes del Sol, la Lluna, la qualitat prevista i els esdeveniments astronòmics continuen accessibles en text a la pàgina «Cel».
