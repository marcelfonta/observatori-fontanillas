# Auditoria d'idiomes · 27 d'octubre de 2026

## Abast

Aquest paquet inventaria 1.605 cadenes catalanes de 13 documents públics i les incorpora al catàleg en castellà, anglès i francès. Inclou text visible, missatges que apareixen durant la navegació, atributs `placeholder`, `aria-label`, `title` i `alt`, metadades de les pàgines independents i manifestos de la PWA. Les quatre pàgines independents incorporen un selector d'idioma.

La prova `tests/i18n-content.mjs` compara l'inventari amb el catàleg, exigeix les tres llengües i verifica que les xifres del text original no canviïn. Les proves de navegador cobreixen el canvi d'idioma i les amplades mòbils.

## Límits i validació pendent

- Els continguts de tercers integrats dins d'un visor o vídeo conserven la llengua que ofereix el proveïdor.
- Els valors oberts que arriben de les API s'han de traduir al lloc on es construeixen; aquest inventari cobreix les cadenes observades durant les proves i els textos dels documents, no qualsevol valor futur.
- Les metadades de les pàgines independents canvien al navegador. Els rastrejadors que no executen JavaScript poden veure la versió catalana; no es promet SEO multilingüe complet per a aquestes pàgines. La ruta de canvi climàtic té tractament de servidor.
- Cal una lectura editorial humana de totes les traduccions abans d'anunciar-les com a definitives, i comprovar-les en iPhone, Android i ordinador després de la fusió. Especialment, les pàgines legals requereixen revisió professional si es vol que les versions traduïdes tinguin valor jurídic.

No s'han modificat dades meteorològiques ni fonts. Aquest paquet no està desplegat fins que el PR sigui revisat i fusionat.
