## Incidència reproduïda

Una consulta HTTP directa a les rutes prioritàries retornava `200`, però l’HTML
inicial de totes elles encara contenia el títol de portada. La funció que ja
preparava títol, descripció, canonical, idioma i JSON-LD per ruta no estava
entrant en el desplegament públic de Cloudflare Pages.

## Correcció aplicada

- `_worker.js` activa explícitament la capa SEO a l’edge i conserva els actius
  estàtics com a alternativa segura.
- Les rutes profundes d’històries i resums reben títol, descripció, canonical,
  imatge social, H1 sense JavaScript i JSON-LD propis.
- Una història incorpora `Article`; el resum mensual incorpora `Report`; el
  Centre de Dades conserva `Dataset` i totes les rutes tenen `WebPage` i
  `BreadcrumbList`.
- Les peces editorials només anuncien el català, perquè el seu cos encara no té
  traduccions completes.
- Una URL editorial inexistent retorna `404` i `X-Robots-Tag: noindex`, evitant
  falsos duplicats i soft 404.
- `npm run audit:seo` comprova el web desplegat i falla si torna a aparèixer el
  títol genèric, una canonical errònia, JSON-LD incomplet o un 404 indexable.

## Seguiment després del desplegament

1. Executar `npm run audit:seo` contra producció.
2. Reenviar `https://meteo.fontanillas.cat/sitemap.xml` a Search Console.
3. Iniciar «Valida la correcció» per les URL detectades i rastrejades sense
   indexar.
4. Inspeccionar primer `/`, `/prediccio`, `/centre-dades`, una història i el
   resum mensual. La validació i la indexació poden trigar dies o setmanes.
