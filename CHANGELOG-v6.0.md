# V6.0

- Substituït LightningMaps per la pàgina oficial de llamps d'AEMET.
- Google Analytics 4 configurable des de `js/config.js`.
- `robots.txt` i `sitemap.xml` per Search Console.
- Web Push amb OneSignal, inclòs suport per PWA en iPhone/iPadOS 16.4+.
- Botó d'activació/desactivació d'avisos a la secció d'avisos.
- Service worker V6 amb API `network-first` per evitar dades congelades.
- Refresc automàtic en tornar a la PWA (`pageshow`, `visibilitychange`, `focus`).
- Detector de nova versió amb banner d'actualització.
- Manifest amb `id` estable per a PWA.
