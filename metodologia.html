Metodologia i Equipament

L'Estació Meteorològica

L'Observatori Fontanillas està situat a Sant Celoni (Montseny). Les dades s'actualitzen en temps real cada 2-5 minuts i es guarden a una base de dades per a anàlisi històric.

Instrumentació

  • Anemòmetre: Velocitat i direcció del vent.
  • Pluviòmetre: Precipitació amb resolució de 0,2 mm.
  • Termo-higròmetre: Protegit dins d'un escut de radiació solar.
  • Baròmetre: Pressió atmosfèrica compensada.
  • Sensor UV i Solar: Índex UV i radiació solar global.

Arquitectura Digital

La web està construïda amb tecnologia moderna de Cloudflare:

  • Cloudflare Pages: Allotjament i desplegament del frontend.
  • Cloudflare Workers: Backend serverless que processa les peticions.
  • Cloudflare D1: Base de dades SQL per emmagatzemar observacions històriques.
  • Weather Underground: Font de les dades meteorològiques en temps real.
