# Code of Conduct

We want participation in Observatori Fontanillas to be welcoming, constructive and safe for everyone.

## Expected behaviour

Be respectful, assume good intent, give specific technical feedback, protect users’ privacy, and prioritise the reliability of weather and safety information.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, doxxing, deliberate misinformation, sharing credentials or personal data, and attempts to bypass security controls are not acceptable.

## Enforcement

Report concerns privately using the contact route in [SUPPORT.md](SUPPORT.md). Maintainers may remove content, reject contributions or restrict participation when needed to protect people or the project. Reports will be handled as discreetly as practical.

This code applies to project spaces and to public interactions representing the project.
