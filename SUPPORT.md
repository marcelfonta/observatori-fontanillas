# Support

## Getting help

- Read the [documentation](README.md#documentation) and existing GitHub issues.
- Use GitHub issues for reproducible bugs and feature proposals; avoid posting sensitive information.
- Use the public contact page at [meteo.fontanillas.cat](https://meteo.fontanillas.cat) for general portal questions or collaboration proposals.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities.

## Scope

The project can help explain how the portal works and correct faults in its presentation. It cannot replace emergency services, official alert authorities, medical advice or provider support for third-party services.
